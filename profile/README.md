RGB is a system of private & scalable client-validated smart contracts on Bitcoin & Lightning developed 
by [LNP/BP Standards Association](https://lnp-bp.org) and maintained by [RGB Consortium](https://consortium.rgb.tech).
You can read more about RGB on [our official site](https://rgb.tech) and in [FAQ](https://rgbfaq.com).

- Standards defining RGB are described in [LNPBP standards](https://github.com/RGB-WG/RFC)
- Reference implementation of consensus/validation code is [RGB Core Library](https://github.com/RGB-WG/rgb-core)
- High-level API to RGB contracts is provided by [RGB Standard Library](https://github.com/RGB-WG/rgb-std)
- To run RGB, you can use [RGB](https://github.com/RGB-WG/rgb) command-line tool or [RGB Node](https://github.com/RGB-WG/rgb-node).
